Scripts used to read xCO2 and xCH4 data from an automated system from General Oceanics Inc. Model 8050 with a LI-7810.

Clone to local folder and run the file run process_data.py (e.g. uv run process_data.py) in for instance pycharm. Make sure to update the path to the carbon data: co2_folder = "your path". If you have access to \Winfs\data\prod\Obs_Oceanografi\Arkiv\Ferrybox\txt, no further actions required. Otherwise you also need to specify location of the quality controlled ferrybox files in process_data.py (update path to fb_folder = "your path"). The scripts are built for the data maintenance within SMHI.
